\# SOC Log Monitoring and Alert System



A centralized Security Operations Center (SOC) monitoring project built with Splunk to detect, investigate, and alert on suspicious security events.



\## Project Overview



This project demonstrates a practical SOC monitoring workflow using Splunk to analyze security logs, identify suspicious activities, and generate security alerts.



\## Objectives



\- Monitor security events using Splunk

\- Detect suspicious login activity

\- Detect brute-force login attempts

\- Correlate failed and successful logins

\- Monitor privileged account activity

\- Detect sudden security event spikes

\- Generate security alerts

\- Monitor events through a SOC dashboard



\## Tools \& Technologies



\- Splunk Enterprise

\- Splunk Search Processing Language (SPL)

\- Windows Security Event Logs

\- Event IDs 4624 and 4625

\- SIEM

\- Security monitoring and alerting



\## Detection Use Cases



1\. Brute Force Login Detection

2\. Failed Login to Successful Login Correlation

3\. Privileged Account Activity Detection

4\. SOC Failed Login Alert

5\. Sudden Security Event Spike Detection



\## Monitoring Workflow



Security Events → Splunk → SPL Detection Rules → Alerts → Dashboard → Investigation



\## Dashboard



The project includes a Splunk dashboard for monitoring security events and suspicious login activity.
